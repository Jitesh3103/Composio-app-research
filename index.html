Executive findings

The pilot is enough to validate the research schema and expose integration trade-offs, but not to claim population-wide percentages.

Patterns visible in the pilot

  • OAuth, API keys, Basic auth and bearer tokens all appear; authentication is product- and API-specific.
  • Self-serve credentials do not imply free API usage. Subscription limits and credits may still gate usage.
  • Multi-tenant OAuth differs materially from single-account API-key integrations.
  • A public API is not automatically an MCP server.

Integration priorities

  • Easy technical wins: documented APIs, self-serve credentials and clear scopes.
  • Extra engineering: OAuth consent, tenant isolation, regional endpoints, metering and rate limits.
  • Human outreach: partner-only, enterprise-only or unclear API entitlements.
  • Never infer: MCP status, free access or endpoint breadth without evidence.

Agent workflow

Automated pipeline

  1. Load app inventory and docs hints.
  2. Search official docs for auth, API surface, access and MCP.
  3. Extract strict structured JSON using an LLM at temperature zero.
  4. Retain only evidence URLs returned by search.
  5. Save each app immediately; unresolved facts become review states.
  6. Human reviewer checks a stratified sample and labels fields.

Where human judgment is required

  • Confirm paid-plan, free-trial, admin and partner restrictions.
  • Distinguish first-party MCP from community projects.
  • Resolve deprecated docs, ambiguous products and enterprise-only APIs.
  • Run live auth tests only with authorized developer accounts.

Stack: Python, Tavily search, OpenAI structured extraction, CSV/JSON. An optional Composio Python SDK session/MCP smoke test is included but requires a real project key and has not been run here.

Verification loop

What gets checked

  • Field-level correctness for auth, access, API surface, MCP and buildability.
  • Official source links for each claim wherever possible.
  • Misses and unresolved facts retained in the review CSV.

Current result

Accuracy: not yet measured.

The project includes a blank verification template and a script that calculates accuracy only after human labels are entered. No first-pass score or improvement is invented.

What to quantify after the full run

Auth mix

Count OAuth, API key, bearer/token and Basic independently; apps can support multiple methods.

Access friction

Separate credential self-service from free usage; track plan, trial, admin, partner and unknown states.

API readiness

REST, GraphQL, SDK-only, private/partner API and no documented public API. Avoid guessed endpoint counts.

MCP readiness

First-party hosted, official local, community, none found and not checked are distinct states.
